# دفتر کلاسی من — نسخه APK با صوت بومی اندروید

این پروژه همان فایل HTML برنامه را داخل یک WebView اندرویدی قرار می‌دهد و برای تشخیص گفتار فارسی از `SpeechRecognizer` خود Android استفاده می‌کند.

## بخش صوتی
- مجوز `RECORD_AUDIO` در Android درخواست می‌شود.
- مجوز میکروفن WebView نیز مدیریت می‌شود.
- تشخیص گفتار با زبان `fa-IR` انجام می‌شود.
- نتیجه مستقیماً داخل کادر متن قرار می‌گیرد و قبل از ذخیره قابل ویرایش است.
- در صورت در دسترس نبودن سرویس تشخیص گفتار، پیام مشخص نمایش داده می‌شود.
- قابلیت ضبط/پخش صوت موجود در HTML نیز با مجوز میکروفن WebView فعال می‌شود.

## ساخت APK بدون Android Studio
این پروژه یک Workflow برای GitHub Actions دارد. کل پوشه را در یک مخزن GitHub قرار دهید، سپس از بخش Actions اجرای `Build APK` را بزنید. فایل APK به‌صورت Artifact تحویل داده می‌شود.
