# دفتر کلاسی من — نسخه 5.3.0

## تغییرات
- اصلاح تاریخ حضور و غیاب ثبت‌شده
- حذف همه رکوردهای حضور و غیاب یک تاریخ با تأیید
- افزودن بخش طراحان برنامه

## ساخت APK
Secrets امضای Release موجود را حفظ کنید و versionCode را کاهش ندهید. نسخه فعلی versionCode=19 و versionName=5.3.0 است.

## حفظ اطلاعات
برای ارتقای عادی، APK جدید را روی نسخه قبلی نصب کنید و برنامه را حذف نکنید یا Clear Data نزنید. برای بازیابی پس از حذف/نصب مجدد، Backend ابری باید ابتدا روی HTTPS و پایگاه داده/فضای ذخیره‌سازی پایدار راه‌اندازی شود. آدرس `window.DAFTAR_CLOUD_ENDPOINT` فعلاً خالی است؛ بنابراین پشتیبان ابری هنوز فعال نیست. تا زمان راه‌اندازی ابری، از بخش «پشتیبان» فایل پشتیبان بگیرید.


## نسخه 5.4.0 — پشتیبان خودکار

در Android 10 و بالاتر، پس از ورود و در اولین اجرای هر روز، برنامه تلاش می‌کند نسخه JSON اطلاعات را در `Download/DaftarKelasiBackups` ذخیره کند. این کار هنگام بازبودن برنامه انجام می‌شود، نه به‌صورت تضمینی در پس‌زمینه. بدون سرور، پس از نصب مجدد باید فایل پشتیبان را بازیابی کرد؛ حساب محلی و رمز عبور خودبه‌خود برنمی‌گردند.
