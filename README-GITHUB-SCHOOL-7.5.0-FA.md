# راهنمای بارگذاری نسخه مدیریت مدرسه در GitHub

1. از نسخه فعلی مخزن و از داده‌های برنامه پشتیبان بگیرید.
2. فایل ZIP پروژه جدید را استخراج کنید.
3. در GitHub وارد مخزن قبلی شوید و از `Add file` گزینه `Upload files` را انتخاب کنید.
4. فایل‌ها و پوشه‌های نسخه جدید را از پوشه `daftar-kelasi-app-main` بارگذاری کنید؛ فقط خود ZIP را به‌عنوان جایگزین سورس آپلود نکنید. اگر GitHub برای فایل‌های هم‌نام پرسید، نسخه جدید را جایگزین کنید.
5. قبل از انتشار نسخه عمومی، بک‌اند PostgreSQL را مستقر کنید، `backend/schema.sql` را اجرا کنید و متغیرهای محیطی را طبق `backend/README.md` تنظیم کنید.
6. پس از استقرار API، در هر دو فایل `index.html` و `app/src/main/assets/index.html` مقدار `window.DAFTAR_CLOUD_ENDPOINT` را به آدرس واقعی API تغییر دهید. هر دو فایل باید دقیقاً یکسان بمانند.
7. پنل `admin.html` را روی میزبانی وب قرار دهید و فقط پس از راه‌اندازی سرور، `admin-setup.html` را به‌صورت موقت برای ایجاد مدیر استفاده کنید. پس از ساخت مدیر، این صفحه را از دسترس عمومی خارج کنید.
8. برای ساخت APK، در GitHub به `Settings → Secrets and variables → Actions` بروید و اسرار امضای اندروید موردنیاز workflow را تنظیم کنید. سپس به `Actions → Build Android Release APK → Run workflow` بروید و APK خروجی را از بخش Artifacts بگیرید.

**مهم:** صرف بارگذاری فایل‌ها در GitHub، سرور و همگام‌سازی آنلاین را فعال نمی‌کند. ابتدا بک‌اند را مستقر و آدرس آن را پیکربندی کنید. اطلاعات آفلاین تا زمان همگام‌سازی موفق در پنل مدیر دیده نمی‌شوند. اطلاعات کاربران پاک نمی‌شود، اما پیش از هر جایگزینی نسخه پشتیبان بگیرید.
