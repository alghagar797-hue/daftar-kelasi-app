# ارتقای مدیریت مدرسه — نسخه 7.5.0

## امکانات اضافه‌شده
- نقش‌های سروری `admin` و `teacher` با کنترل دسترسی مبتنی بر نقش.
- ساخت یک مدرسه و مدیر اولیه از طریق مسیر محافظت‌شده راه‌اندازی.
- کد عضویت برای اتصال معلمان به مدرسه.
- امکان پیوستن حساب معلم قبلی به مدرسه بدون حذف snapshot محلی.
- پنل وب `admin.html` برای مشاهده تعداد معلمان، دانش‌آموزان، کلاس‌ها و خلاصه رکوردهای حضور و غیاب همگام‌شده.
- پنل مدیر در اپلیکیشن برای حساب مدیر آنلاین.
- مشاهده snapshot همگام‌شده هر معلم فقط توسط مدیر مدرسه مربوطه.
- افزودن ساختار `schools`, `teachers.role` و `teachers.school_id` با SQL سازگار با نصب‌های قبلی.
- افزایش نسخه Android به `7.5.0` و هماهنگ‌سازی فایل HTML وب و Android.
- اعتبارسنجی نوع فایل آپلود و محدودیت حجم payload همگام‌سازی.

## حفظ اطلاعات قبلی
داده‌های محلی در IndexedDB و localStorage حذف یا پاک‌سازی نمی‌شوند؛ هنگام ورود ابری، نسخه محلی قبل از ادغام پشتیبان‌گیری می‌شود و به‌جای جایگزینی کامل، داده‌های محلی و ابری با هم ادغام می‌شوند. پیش از ارتقا، از بخش پشتیبان برنامه خروجی بگیرید. ابتدا نسخه جدید را با کپی آزمایشی و یک حساب آزمایشی بررسی کنید. برای دیدن اطلاعات معلم در پنل، حساب او باید به مدرسه متصل باشد و snapshot آن به سرور همگام شده باشد.

## محدودیت مهم
این نسخه یک لایه مدیریتی روی snapshotهای جداگانه معلمان اضافه می‌کند؛ هنوز پایگاه داده نرمال‌شده مستقل برای دانش‌آموزان و حضور و غیاب یا همگام‌سازی بلادرنگ بین دستگاه‌ها ندارد. گزارش مدیر بر اساس آخرین snapshotهای همگام‌شده است و ممکن است تا زمان اتصال دستگاه معلم به‌روز نباشد. برای استفاده واقعی با اطلاعات حساس، HTTPS، پایگاه داده پشتیبان‌گیری‌شده و فضای فایل خصوصی لازم است.

## فایل‌های تازه
- `admin.html`: پنل وب مدیر.
- `admin-setup.html`: ساخت اولیه مدیر؛ پس از استفاده عمومی نماند.
- متغیرهای محیطی موردنیاز در `backend/README.md` توضیح داده شده‌اند؛ مقادیر واقعی را فقط در تنظیمات امن سرویس میزبانی قرار دهید.
- `backend/index.js`: سرور فعلی؛ در این نسخه فایل مستقل `schema.sql` وجود ندارد.
- `backend/README.md`: راهنمای نصب و استقرار.
