# دفتر کلاسی من — نسخه 4.2.0

## هسته آفلاین/همگام‌سازی
- ذخیره محلی اتمیک قبل از هر تلاش برای همگام‌سازی.
- صف تغییرات در IndexedDB با revision یکتا و retry با backoff.
- در قطع اینترنت داده‌ها روی دستگاه باقی می‌مانند.
- ارسال ابری فقط وقتی `DAFTAR_SYNC_ENDPOINT` عمداً از سمت Backend رسمی برنامه تنظیم شده باشد.
- تا قبل از تنظیم Backend، هیچ داده‌ای به سرویس شخص ثالث ارسال نمی‌شود.

## قرارداد Backend
Endpoint باید POST JSON با این ساختار دریافت کند:
`{ username, revision, payload }`
و در موفقیت HTTP 2xx برگرداند. برای محیط واقعی باید احراز هویت امن، TLS، کنترل دسترسی، versioning و conflict resolution در سرور پیاده‌سازی شود.

## حفظ امکانات
این نسخه هیچ بخش موجود برنامه را حذف نمی‌کند و تغییرات فقط در لایه ذخیره‌سازی، صف Sync و پایداری اعمال شده‌اند.
