# دفتر کلاسی من — نسخه 4.0.0 نهایی آماده GitHub

این نسخه برای قرار دادن در GitHub و ساخت APK با GitHub Actions آماده شده است.

## ساخت APK
1. محتوای پوشه `daftar` را در ریشه یک Repository گیت‌هاب قرار دهید.
2. به تب **Actions** بروید.
3. Workflow با نام **Build Android APK** را اجرا کنید.
4. پس از پایان موفق، از بخش **Artifacts** فایل `daftar-kelasi-man-debug-apk` را دریافت کنید.

این APK نسخه Debug است و برای نصب و تست روی گوشی مناسب است.
