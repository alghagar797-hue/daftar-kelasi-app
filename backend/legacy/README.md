# نسخهٔ قدیمی سرور (legacy/server.js)

این فایل نسخهٔ قدیمی سرور (v2، با bcrypt و ساختار جداول متفاوت) است که **دیگر اجرا نمی‌شود و به آن وابسته نیستید**؛ صرفاً برای حفظ سابقه نگه داشته شده است. سرور فعال، `backend/index.js` (v3.2.0) است که با `npm start` اجرا می‌شود و جداول `dk_*` را خودش می‌سازد.

اگر به داده‌ای از نسخهٔ خیلی قدیمی روی سرور قبلی دارید، ابتدا از همان سرور خروجی بگیرید و با پشتیبان JSON وارد برنامه کنید — این فایل را اجرا نکنید.
