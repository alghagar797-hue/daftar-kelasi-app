# Backend دفتر کلاسی من

این سرویس برای حساب معلم، ورود امن، همگام‌سازی آنلاین/آفلاین و بارگذاری فایل آماده است.

## راه‌اندازی
1. PostgreSQL بسازید و `schema.sql` را اجرا کنید. PostgreSQL باید قابلیت `pgcrypto` برای `gen_random_uuid()` داشته باشد؛ در صورت نیاز `CREATE EXTENSION IF NOT EXISTS pgcrypto;` را قبل از schema اجرا کنید.
2. متغیرهای `.env.example` را تنظیم کنید.
3. `npm install` و سپس `npm start`.
4. آدرس `https://...` سرویس را در تنظیمات Cloud برنامه قرار دهید.

## امنیت
- رمز عبور هرگز به صورت متن ذخیره نمی‌شود و با bcrypt ذخیره می‌شود.
- API با JWT محافظت می‌شود.
- هر معلم فقط snapshot حساب خودش را می‌بیند.
- فایل‌ها به صورت جداگانه ذخیره می‌شوند.
- برای محیط واقعی حتماً HTTPS و فضای ذخیره‌سازی شیءگرا/پایدار استفاده شود؛ دیسک محلی سرور برای تولید نهایی مناسب نیست.

## ظرفیت
تعداد حساب در منطق برنامه محدود نشده است. ظرفیت واقعی تابع منابع PostgreSQL، فضای فایل و زیرساخت است.


## تنظیم CORS و محدودیت‌های فعلی
- مقدار `CORS_ORIGIN` باید شامل مبدأهای دقیق نسخه وب باشد؛ وقتی مبدأ مرورگر در این فهرست نباشد، پاسخ از طریق CORS در اختیار آن صفحه قرار نمی‌گیرد.
- درخواست‌های بدون هدر `Origin` (برای نمونه بعضی درخواست‌های native/CLI) همچنان توسط این قاعده CORS مسدود نمی‌شوند؛ این موضوع جایگزین احراز هویت نیست.
- مسیر آپلود فعلی هنوز اعتبارسنجی allowlist برای نوع محتوا/پسوند و مسیر دانلود خصوصی مبتنی بر مالکیت فایل ندارد. پیش از استفاده واقعی از فایل‌های دانش‌آموزان، این بخش باید تکمیل شود.
- در نسخه HTML فعلی مقدار `DAFTAR_CLOUD_ENDPOINT` خالی است؛ بنابراین بک‌اند آنلاین به‌صورت خودکار فعال نشده است.
