# دفتر کلاسی من — نسخه 4.4.0

## سخت‌سازی نسخه انتشار
- حفظ همه امکانات نسخه‌های قبل.
- Sync آفلاین‌محور با صف محلی.
- جلوگیری از overwrite ناخواسته در تعارض Sync؛ در تعارض، داده محلی و نسخه سرور هر دو حفظ می‌شوند تا داده از بین نرود.
- ثبت revision سرور برای هر حساب.
- حذف CORS باز در محیط تولید و الزام origin مشخص.
- فعال‌سازی اعتبارسنجی TLS برای PostgreSQL غیرمحلی.
- محدودیت بدنه JSON و کنترل حجم فایل در Backend.
- حذف x-powered-by از Express.
- نسخه برنامه: 4.4.0 / versionCode 11.
- طراح: محمد حسین ممشلی.

## استقرار واقعی
Backend باید روی HTTPS، PostgreSQL پایدار و برای فایل‌های حجیم روی Object Storage سازگار با S3 مستقر شود.


## نسخه 4.4.0 — Professional Stability

- اسکرول عمودی سراسری برای تمام صفحات و فهرست‌ها، از جمله فهرست دانش‌آموزان.
- حذف محدودیت لمسی `pan-x` که می‌توانست حرکت عمودی را در جدول‌ها و لیست‌ها مختل کند.
- IndexedDB حساب‌ها از نسخه 3 به 4 ارتقا یافت و Store نسخه پشتیبان مهاجرت اضافه شد؛ هیچ Store یا رکورد قدیمی در Migration حذف نمی‌شود.
- داده‌های برنامه دارای `dataSchemaVersion` هستند و Migration به‌صورت افزایشی انجام می‌شود.
- قبل از Migration داده‌ای، در صورت امکان یک نسخه پشتیبان داخلی از داده قبلی نگهداری می‌شود.
- هنگام دریافت داده ابری قدیمی، داده قبل از ذخیره محلی با Schema فعلی سازگار می‌شود.
- `versionCode` به 11 و `versionName` به 4.4.0 افزایش یافت؛ `applicationId` ثابت باقی مانده است تا مسیر ارتقای APK حفظ شود.
- هدف این نسخه: حفظ داده‌ها در به‌روزرسانی‌های آینده، کارکرد آفلاین، Sync آنلاین و اجرای روان‌تر روی دستگاه‌های کم‌توان.
