## ساخت Release در GitHub
Workflow فقط وقتی APK می‌سازد که کلید امضای Release به‌صورت GitHub Secrets تنظیم شده باشد. اگر Secrets ناقص باشند، Build عمداً متوقف می‌شود و APK بدون امضا تولید نمی‌کند.

Secrets لازم:

1. `ANDROID_KEYSTORE_BASE64`
2. `ANDROID_KEYSTORE_PASSWORD`
3. `ANDROID_KEY_ALIAS`
4. `ANDROID_KEY_PASSWORD`

کلید keystore را **هرگز داخل Repository قرار ندهید**.

پس از تنظیم Secrets:
1. وارد GitHub > Actions شوید.
2. Workflow با نام `Build Signed Android Release` را انتخاب کنید.
3. روی `Run workflow` بزنید.
4. بعد از سبز شدن Build، Artifact با نام `daftar-kelasi-man-release-apk` را دانلود کنید.

## نکته مهم درباره امضای برنامه
همان keystore باید برای تمام نسخه‌های آینده استفاده شود. اگر کلید امضا گم شود، انتشار به‌روزرسانی همان برنامه می‌تواند با مشکل مواجه شود.

## گفتار فارسی
عملکرد SpeechRecognizer به موتور گفتار نصب‌شده روی دستگاه و وجود مدل زبان فارسی وابسته است. برنامه برای این مورد پیام خطای مشخص نمایش می‌دهد و عملکرد آفلاین فقط در دستگاه‌هایی ممکن است که مدل فارسی را داشته باشند.
