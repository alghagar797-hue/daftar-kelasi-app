# نسخه ۷ — طراحی داشبورد + بودجه‌بندی تدریس کتاب

- طراحی داشبورد به سبک کارت‌های مدرن، رنگی و مناسب موبایل نزدیک‌تر شد.
- دسترسی سریع به امکانات اصلی کلاس در داشبورد اضافه شد.
- پیش‌نمایش جدول ساعات تدریس در داشبورد اضافه شد.
- بخش «بودجه‌بندی تدریس کتاب» اضافه شد.
- جدول بودجه‌بندی کتاب برای ماه‌های مهر تا اردیبهشت و درس‌های اصلی دوره ابتدایی اضافه شده و خانه‌ها قابل ویرایش و ذخیره هستند.
- اطلاعات بودجه‌بندی کتاب برای هر پایه جداگانه و به‌صورت آفلاین ذخیره می‌شود.
- بخش بودجه ساعات تدریس نسخه قبل حفظ شده و جدول آن قابل ویرایش است.
- کلاس چندپایه و پایه مستقل دانش‌آموزان حفظ شده است.
