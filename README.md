# دفتر کلاسی من — Daftar Kelasi Man

اپلیکیشن مدیریت کلاس و مدرسه، **کاملاً آفلاین‌محور**، با رابط کاربری فارسی و راست‌به‌چپ، تقویم شمسی و گزارش‌های PDF فارسی. این مخزن نسخه **8.3.0** را در بر دارد که و خروجی PDF برای بخش‌های داده‌ای را اضافه می‌کند. گزارش آزمون‌های قدیمی نسخه ۸٫۲٫۰ به‌تنهایی اثبات آزمون کامل نسخه ۸٫۳٫۰ نیست.

- Application ID: `com.classroom.daftar`
- Version: `8.3.0` / versionCode: `41`
- minSdk: `23` · targetSdk: `36` · JDK: `17` · Gradle: `8.13`

---

## مهم‌ترین تغییرات نسخه 8.3.0

- **خروجی PDF برای تمام بخش‌ها (جدید):** هر ۱۷ بخش داده‌ای برنامه (دانش‌آموزان، تکالیف، ارزشیابی‌ها، ارزشیابی کیفی، بازخوردها، عملکرد ماهانه، نیازمند توجه، والدین، علاقه‌مندی‌ها، دفتر روزانه، برنامهٔ هفتگی، بودجه‌بندی ساعات، بودجه‌بندی کتاب، آزمایش‌ها، گروه‌بندی، پوشه‌کار و کارتابل دانش‌آموز) دکمهٔ «📄 خروجی PDF» دارد — فارسی، RTL، تاریخ شمسی، شمارهٔ صفحهٔ فارسی، صفحه‌بندی بدون بیرون‌زدگی و کاملاً آفلاین. جزئیات: `CHANGELOG-8.3.0-FA.md`

## مهم‌ترین تغییرات نسخه 8.2.0

- **حالت آفلاین صادقانه:** ذخیره‌سازی محلی (IndexedDB) بدون هیچ وابستگی اجباری به سرور؛ نوار وضعیت واقعی «ذخیره محلی · بدون سرور» به‌جای ادعای غیرواقعی همگام‌سازی.
- **بسته اشتراک امن مدرسه (جدید):** انتقال داده از معلم به مدیر مدرسه بدون سرور — فایل رمزنگاری‌شده با `AES-256-GCM` + امضای `HMAC-SHA256` + استخراج کلید `PBKDF2` (۲۰۰ هزار دور). تشخیص دستکاری، تکراری و کهنه‌بودن بسته؛ گزارش PDF اختصاصی برای مدیر.
- **پشتیبان‌گیری/بازیابی سالم:** فرمت یکپارچه با متادیتای نسخه، پیش‌نمایش قبل از بازیابی، اسنپ‌شات ایمنی قبل از بازنویسی، و مسیر بازگشت در صورت خرابی مهاجرت.
- **گزارش PDF واقعی:** تولید PDF با canvas کاملاً آفلاین (بدون پنجره print که در WebView اندروید کار نمی‌کند) — تاریخ شمسی، اعداد فارسی و عکس دانش‌آموز حفظ می‌شود.
- **امنیت حساب:** هش رمز عبور از SHA-256 ساده به `PBKDF2-SHA256` با نمک (۱۵۰ هزار دور) ارتقا یافت؛ ورود با هش قدیمی شفاف ارتقا می‌یابد.
- **اندروید:** حذف کد مرده `com.classnotebook.app`، باز شدن صحیح لینک‌های خارجی، همگام‌سازی خودکار `index.html` با asset اندروید در CI.
- **بک‌اند (اختیاری):** نسخه `3.2.0` با قفل همزمانی push، نوشتن اتمی فایل، محدودسازی نرخ درست و هدرهای امنیتی. اجرای آن **کاملاً اختیاری** است؛ برنامه بدون سرور هم کامل کار می‌کند.

جزئیات کامل: `CHANGELOG-8.2.0-FA.md` · گزارش آزمون‌ها: `TEST-REPORT-EN.md`

## ساخت APK روی GitHub (بدون Android Studio)

۱. کل مخزن را به GitHub پوش کنید.
۲. در `Settings → Secrets and variables → Actions` چهار Secret بسازید:

| نام Secret | مقدار |
|---|---|
| `KEYSTORE_BASE64` | محتوای Base64 فایل keystore |
| `KEYSTORE_PASSWORD` | رمز keystore |
| `KEY_ALIAS` | نام مستعار کلید |
| `KEY_PASSWORD` | رمز کلید |

۳. به تب `Actions` بروید و workflow با نام **Build Android Release APK** را اجرا کنید (یا push به `main`).
۴. پس از سبز شدن Build، Artifact با نام **`DaftarKelasi-APK-v8.3.0`** را دانلود کنید.

راهنمای کامل: `BUILD-APK-FA.md` و `SECRETS-SETUP-FA.md`

> ⚠️ **امنیت:** فایل keystore و رمزها را **هرگز** داخل مخزن commit نکنید (`.gitignore` از این موضوع محافظت می‌کند). اگر کلید امضا منتشر شود، به‌روزرسانی نصبیِ قبلی ممکن نخواهد بود.
